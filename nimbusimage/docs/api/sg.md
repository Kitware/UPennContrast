# Spatial Genomics ingest

Load one ROI of a Spatial Genomics (GenePS / sganalysis) export into NimbusImage. Needs
`pip install 'nimbusimage[sg]'`. Every step is also a subcommand of the `nimbusimage-sg`
command.
